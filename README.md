# Сбор отзывов из App Store ⭐

Python-приложение с веб-интерфейсом на Streamlit, которое выкачивает отзывы приложений из бесплатного публичного RSS-фида Apple для российского и американского сторов, удаляет повторы и накапливает их в CSV-файле.

## Ключевые возможности

- 🌍 Сбор отзывов из двух сторов: Россия (`ru`) и США (`us`) — список стран задаётся в [`config.py`](config.py).
- 🗣️ Выбор языка отзывов: русский, английский (США и Великобритания), немецкий, французский, испанский, китайский — словарь `LANGUAGES` в [`config.py`](config.py). Язык определяет, из какого стора собираются отзывы: русские — из `ru`, английские США — из `us` и т.д. Для локалей вида `xx_yy` (`en_us`, `en_gb`) дополнительно передаётся параметр `?lang=...`.
- 🔄 Ретраи пустых страниц: у RSS Apple бывают случайные «дыры» — пустые страницы в середине выборки; такие страницы повторяются несколько раз (`EMPTY_PAGE_RETRIES` / `RETRY_PAUSE` в [`config.py`](config.py)), а для локалей `xx_yy` есть последний шанс — запрос без языкового параметра.
- 📄 До 10 страниц фида на страну, до 50 отзывов на страницу (настройки `MIN_PAGES` / `MAX_PAGES` / `DEFAULT_PAGES`).
- 🧹 Дедупликация: внутри запуска по служебному `review_id`, против уже сохранённых данных — по составному ключу «автор + дата + заголовок» (см. [`storage.py`](storage.py)).
- 📦 Дополнительные поля отзыва: **версия приложения** (`app_version`) и **ответ разработчика** (`developer_response`) — сохраняются в CSV вместе с остальными данными.
- 💾 Накопление данных: новые отзывы добавляются к уже лежащим в `reviews.csv`, файл пишется в `utf-8-sig`, поэтому кириллица корректно открывается в Excel. Старый CSV без новых колонок читается без ошибок — недостающие поля просто остаются пустыми.
- 🖥️ Веб-интерфейс: прогресс-бар загрузки, метрики (всего отзывов, средний рейтинг), гистограмма оценок, таблица и кнопка скачивания CSV (см. [`app.py`](app.py)).
- ⚠️ Понятная обработка ошибок: ограничение частоты запросов Apple (HTTP 403), сетевые сбои и таймауты, невалидный JSON ([`fetcher.py`](fetcher.py)).
- 🔀 Чистое разделение слоёв: сеть, парсинг, хранение и интерфейс не зависят друг от друга напрямую.

## Требования

- **ОС:** Windows, macOS или Linux.
- **Python 3.10+** (в коде используется синтаксис `X | None` в аннотациях).
- **Браузер** для веб-интерфейса (Streamlit открывает локальную страницу):
  - Google Chrome / Microsoft Edge 90+
  - Mozilla Firefox 90+
  - Safari 14+
- Доступ в интернет — приложение ходит на `itunes.apple.com`.
- Зависимости из [`requirements.txt`](requirements.txt):

```
requests
streamlit
pandas
```

## Установка

1. Склонируйте или скачайте проект и перейдите в его папку:

   ```powershell
   cd appStore_scrap_python
   ```

2. (Рекомендуется) создайте виртуальное окружение:

   ```powershell
   python -m venv .venv
   .venv\Scripts\Activate.ps1      # Windows PowerShell
   source .venv/bin/activate       # macOS / Linux
   ```

3. Установите зависимости:

   ```powershell
   pip install -r requirements.txt
   ```

## Запуск

1. Запустите Streamlit-приложение:

   ```powershell
   streamlit run app.py
   ```

2. Браузер откроется автоматически на `http://localhost:8501`.
3. В поле ввода укажите **App ID приложения** (только цифры, например `597986893`).
4. Ползунком выберите, сколько страниц фида собирать (1–10 на страну).
5. В списке **«Язык отзывов»** выберите язык: русский (из ru-стора), английский США (из us-стора) и т.д. — стор выбирается автоматически.
6. Нажмите **«Собрать отзывы»** — прогресс-бар покажет, какая страница и страна обрабатываются.
7. Результат смотрится прямо на странице и накапливается в `reviews.csv`; кнопка **«Обновить данные»** перечитывает файл, а **«Скачать CSV»** выгружает текущий набор. В таблице, помимо базовых колонок, отображаются версия приложения и ответ разработчика (если он оставлен).

Все настройки (страны, пауза и таймаут запросов, границы слайдера, имя файла) меняются в одном месте — [`config.py`](config.py).

### Описание директорий и файлов

- [`app.py`](app.py) — точка входа и слой представления. Только виджеты Streamlit и вывод данных; вся логика вызывается через одну функцию `collect_reviews`. Здесь же перехватываются и красиво показываются исключения.
- [`scraper.py`](scraper.py) — оркестратор: в цикле обходит страны и страницы, склеивает `fetcher` → `parser` → `storage` и возвращает объединённый список отзывов.
- [`fetcher.py`](fetcher.py) — только сеть: формирует URL по шаблону (включая параметр языка), соблюдает паузу между запросами, различает 403 (ограничение Apple), прочие статусы и невалидный JSON.
- [`parser.py`](parser.py) — только парсинг: превращает JSON-записи фида в модели `Review`, терпимо относится к отсутствующим полям, приводит даты к формату `ГГГГ-ММ-ДД` и достаёт версию приложения (`im:version`) и ответ разработчика (`im:response`).
- [`storage.py`](storage.py) — только файлы: читает и пишет `reviews.csv` (в `utf-8-sig` для Excel), дедуплицирует отзывы и возвращает данные для интерфейса.
- [`models.py`](models.py) — нижний уровень: dataclass `Review` (автор, дата, рейтинг, заголовок, текст, страна, версия приложения, ответ разработчика) и метод `to_row()` для CSV; никого из проекта не импортирует.
- [`config.py`](config.py) — константы: шаблон URL фида, страны, список языков отзывов `LANGUAGES`, паузы, таймауты, границы слайдера и имя файла.
- `reviews.csv` — файл данных; создаётся автоматически при первом запуске, `review_id` в него не пишется.

## Как это работает

Данные проходят путь: `fetcher` скачивает страницу фида (с выбранным языком, при пустом ответе — повторно без языкового фильтра) → `parser` разбирает её в список `Review` с версией приложения и ответом разработчика → `storage` дедуплицирует и дописывает в CSV → `app` показывает результат. Ошибки не глотаются: `RateLimitError`, `NetworkError` и `ValueError` пробрасываются до интерфейса.

Итоговые колонки CSV:

| Колонка | Описание |
|---|---|
| `author` | автор отзыва |
| `date` | дата в формате `ГГГГ-ММ-ДД` |
| `rating` | оценка 1–5 |
| `title` | заголовок отзыва |
| `review` | текст отзыва |
| `country` | код стора (`ru`, `us`) |
| `app_version` | версия приложения, о которой отзыв |
| `developer_response` | ответ разработчика, если он оставлен |

Служебный `review_id` используется только для дедупликации внутри запуска и в файл не пишется.

Полезные ссылки для понимания форматов и веб-технологий, с которыми работает проект:

- [MDN: Обзор HTTP](https://developer.mozilla.org/ru/docs/Web/HTTP) — статусы ответов, включая `403 Forbidden`;
- [MDN: Работа с JSON](https://developer.mozilla.org/ru/docs/Learn/JavaScript/Objects/JSON) — структура фида Apple;
- [MDN: Кодировки и Encoding API](https://developer.mozilla.org/ru/docs/Web/API/Encoding_API) — почему CSV пишется в `utf-8-sig`;
- [MDN: Fetch API](https://developer.mozilla.org/ru/docs/Web/API/Fetch_API) — как те же запросы выглядели бы в браузере.
